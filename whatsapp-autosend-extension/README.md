# ⚡ Ostan WhatsApp Auto-Sender Extension

This lightweight Chrome & Edge Extension makes the entire WhatsApp messaging dispatch in Ostan **100% automatic**!

## How it works:
1. When Ostan launches a WhatsApp message with the Anti-Ban delay timer, WhatsApp Web opens.
2. This extension immediately detects the chat and pre-filled text.
3. It **automatically clicks the green Send button** (and triggers Enter key) without you pressing anything!
4. It automatically closes the tab after 2.5 seconds.
5. Ostan moves to the next recipient after the delay timer countdown!

## 🚀 How to Install in 3 Easy Steps:

### Google Chrome:
1. Open Chrome and go to: `chrome://extensions`
2. Turn ON the **"Developer mode"** toggle in the top-right corner.
3. Click the **"Load unpacked"** button in the top-left corner.
4. Select this folder: `c:\Users\wasee\Desktop\Test\whatsapp-autosend-extension` (or wherever your project is located).
5. Done! The extension is now active.

### Microsoft Edge:
1. Open Edge and go to: `edge://extensions`
2. Turn ON the **"Developer mode"** toggle in the left menu.
3. Click the **"Load unpacked"** button.
4. Select this folder: `whatsapp-autosend-extension`.
5. Done!
